03 O que eu aprendi

painéis

Bateria verde não substitui abrir a tela e olhar.

power automate

"Aceito" não é "entregue". A prova é a mensagem chegando.

git

O que entra no histórico do repositório não sai mais. Dado pessoal nunca sobe.

dados

Dois sistemas só se comparam na mesma data de corte. Senão a diferença é do relógio, não do dado.

apps

Controle de acesso dentro do arquivo é cosmético. Segurança mora no servidor.

requisitos

Pedido que chega em forma de lista costuma ser uma regra disfarçada. Escrever a regra, não a lista.
